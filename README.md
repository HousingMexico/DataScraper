# DataScraper
## _Scrape housing information, made easy._

This scraper intends to collect ***public information only*** from several real estate agencies. This data is then cleaned and stored.

- Send a request to the site
- Fetch a specific estate's information
- Clean the data up and save specific datafields
- Store the collected information into a database


## Tech

DataScraper makes use of a wide stack of technologies:

- Python - Overall programming language due to its simplicity
- Requests - Manage website access links
- BeautifulSoup4 - Obtain specific data fields
- MySQL - Store the information in a database
- Pandas - Work with the data obtained


## About

With this repository we intend to collect data ahead of building a Machine Learning model, which requires a very wide array of real estate information, such as location, size, bedrooms, bathrooms, etcetera. The scraper collects that information, makes basic cleanup and then stores it. Once the information has been obtained, another project will make final data cleanup ahead of Model training.
